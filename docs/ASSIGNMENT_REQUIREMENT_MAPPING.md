# Assignment requirement mapping

| Assignment requirement | Where it is implemented / demonstrated |
|---|---|
| Flutter-based Task Manager | `lib/` Flutter application, iOS target generated by `scripts/bootstrap_ios.sh` |
| Back4App BaaS | `lib/config/back4app_config.dart`, Parse SDK dependency |
| Register with student email | `RegisterScreen`, configurable college domain validator |
| Login | `LoginScreen` + `AuthService.login()` |
| Credentials handled by Back4App auth | Parse `_User`, no custom password database |
| Create task | `TaskFormScreen` + `TaskService.createTask()` |
| Read tasks | `ParseLiveListWidget` in `HomeScreen` |
| Update task | Edit form + status toggle + `TaskService.updateTask()` |
| Delete task | Task action menu + confirmation + `TaskService.deleteTask()` |
| Cloud storage | Back4App `Task` class |
| Real-time syncing | Parse Live Query / `ParseLiveListWidget`; Back4App Live Query must be enabled for `Task` |
| Secure logout | `AuthService.logout()` invalidates the current Parse session |
| GitHub repository | Entire folder is repo-ready; `.gitignore` prevents credential commit |
| README + screenshots | `README.md` + `assets/screenshots/` |
| 2-minute video | `docs/VIDEO_SCRIPT_2_MIN.md` |
| PPT presentation | `MTech_Task_Manager_Presentation.pptx` in project root |
