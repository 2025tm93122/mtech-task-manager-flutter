# Pre-recording checklist

- [ ] iPhone Simulator is booted and the app launches cleanly.
- [ ] Back4App Application ID and Client Key are loaded via `.back4app.env`.
- [ ] `Task` class exists in Back4App.
- [ ] Live Query is enabled for `Task`.
- [ ] Student account credentials are ready.
- [ ] Back4App Database tab is open and zoomed so rows are readable.
- [ ] There are zero or very few old tasks, so CRUD is easy to see.
- [ ] macOS notifications are muted during recording.
- [ ] Simulator is at a readable scale.
- [ ] Follow `VIDEO_SCRIPT_2_MIN.md` and keep the demo under two minutes.
