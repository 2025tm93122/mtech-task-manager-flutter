# GitHub and Taxila submission steps

## Initialize Git

```bash
git init
git add .
git commit -m "M.Tech SE ZG585 Flutter Back4App Task Manager"
```

Create a new GitHub repository in your account, then run the commands GitHub shows, typically:

```bash
git branch -M main
git remote add origin <YOUR_REPOSITORY_URL>
git push -u origin main
```

Before pushing, run:

```bash
git status
```

Confirm `.back4app.env` is **not** staged.
